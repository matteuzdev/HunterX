# Elite Site Architecture

Use this skill as the default visual/UX standard for client websites unless the project already has stronger explicit art direction.

## Phase 0 — Research before layout
Before coding, consolidate real evidence about the business: official name, city/state, public contact channels, services, visual identity, reputation, projects, current website/social presence and differentiators. Never invent CNPJ, reviews, testimonials, ratings, awards, customers, project photos or credentials.

## Anti-AI visual rules
- Do not default to the clichéd two-column hero with copy left + rounded stock image right.
- Prefer a centered cinematic hero / showcase frame with strong editorial hierarchy.
- Do not use decorative emojis in the site body. Use consistent vector icons.
- Ban generic copy such as “somos apaixonados”, “soluções completas”, “líderes com excelência” and “a melhor escolha”.
- Use concrete, business-specific language and real technical differentiators.
- Avoid monotonous equal-card grids. Use hierarchical bento composition with a clear anchor card.
- Motion must be restrained and purposeful: reveal, parallax-lite, hover depth, marquee only when justified, and smooth state transitions.

## Composition system
1. Cinematic centralized hero with refined display typography, one dominant visual/showcase frame and up to two glass information cards.
2. Hierarchical bento section for services, environments, use cases or product capabilities.
3. Interactive tabs for categories/materials/capabilities when the content genuinely benefits from comparison.
4. Before/after or interactive comparison only when real source material exists.
5. Social proof only from genuine verifiable reviews. If none are available, replace this module with proof of process, portfolio, metrics that are actually known, or remove it.
6. Conversion section with real contact/location/CTA information.

## Copy
Write for concrete pains, desired outcomes and buying objections. Use CBVL thinking when useful:
- Característica: what exists.
- Benefício lógico: practical result.
- Vantagem: why this approach is preferable in context.
- Ligação emocional: confidence, control, status, relief or identity — without manufactured urgency or guarantees.

## Mobile
Mobile-first. No accidental horizontal overflow. Thumb-friendly controls. Full-width primary CTAs where appropriate. Horizontal tabs may scroll with inertia. Navigation should become a polished drawer, not a squeezed desktop menu.

## Technical default for local client sites
If there is no pre-existing stack constraint, prefer semantic HTML5 + CSS custom properties + clean Vanilla JS for lightweight sites. If the project already uses Next.js/React or another established stack, keep that stack and apply the same art-direction principles instead of forcing a rewrite.

Include:
- local-intent meta description,
- Open Graph metadata,
- appropriate Schema.org markup using verified facts only,
- accessible headings/labels,
- fast assets and responsive images,
- clean footer and contact CTAs.

## Delivery gate
Before shipping:
- verify mobile at common widths,
- verify no fake data,
- verify CTA/contact links,
- verify interaction states,
- verify contrast and keyboard focus,
- verify performance regressions,
- remove visual clichés that make the page look AI-generated.
